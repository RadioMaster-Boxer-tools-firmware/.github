# .github
RadioMaster Boxer Tools &amp; Firmware — набор программных инструментов, прошивок и ресурсов для настройки передатчика RadioMaster Boxer. Экосистема включает EdgeTX, ExpressLRS, EdgeTX Companion, ExpressLRS Configurator, SD Card Content и инструменты обновления для управления моделями, ELRS-модулем, Lua-скриптами и резервными копиями.
